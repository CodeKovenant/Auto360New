3️⃣ Report Business Form

Add a “Report Business” section at the bottom of the profile page.

Fields:

Name

Email

Reason for reporting (Dropdown: Fake listing / Scam / Misleading info / Other)

Description (optional)

Submit button

API endpoint:

POST /api/report

Stores the report in the database:

Report {
  businessId: ObjectId
  name: String
  email: String
  reason: String
  description: String
  createdAt: Date
}

Admin can view and act on reported businesses via Admin Dashboard.
