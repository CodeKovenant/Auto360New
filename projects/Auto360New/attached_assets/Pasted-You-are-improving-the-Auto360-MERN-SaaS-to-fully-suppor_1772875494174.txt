3️⃣ Database Updates
Business Schema
Business {
  name: String,
  type: String, // Automobile Dealer, Auto Spare Part Dealer, Auto Garage, Automotive Support
  description: String,
  logo: String,
  phone: String,
  whatsapp: String,
  email: String,
  address: String,
  city: String,
  location: { type: "Point", coordinates: [longitude, latitude] },
  approved: Boolean,
  ownerId: ObjectId,
  products: [
    {
      name: String,
      description: String,
      startingPrice: Number,
      image: String,
      carBrand: String, // for spare parts
      carModel: String // for spare parts
    }
  ],
  services: [
    {
      name: String,
      description: String,
      startingPrice: Number,
      image: String
    }
  ],
  createdAt: Date
}
Spare Part Schema
SparePart {
  name: String,
  carBrand: String,
  carModel: String,
  description: String,
  startingPrice: Number,
  image: String,
  dealerId: ObjectId,
  createdAt: Date
}
Insurance / Automotive Support Service Schema
SupportService {
  name: String,
  description: String,
  startingPrice: Number,
  image: String,
  businessId: ObjectId,
  createdAt: Date
}
4️⃣ API Updates

GET /api/business/:id — returns business info + products/services + location

GET /api/products/:businessId — for spare parts

GET /api/services/:businessId — for garage or support services

POST /api/report — submit reported businesses

GET /api/reviews/recent — recent reviews for homepage

GET /api/brands/popular — popular brands for homepage
