You are improving an existing MERN stack automotive marketplace SaaS.

The platform already includes:

User authentication (JWT)

Business registration

Admin approval system

Business profiles

Spare part listings

Reviews

Search with filters

Contact via WhatsApp or form

However, two important features are missing:

Garages cannot display services as listing cards

Your task is to implement these features fully.

  images: [String]

Create API endpoints:

POST /api/cars
GET /api/cars
